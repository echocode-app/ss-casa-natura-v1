# Casa Natura – Керівництво для клієнта (UA)

Цей документ описує, як керувати магазином Casa Natura з боку бізнесу.

## Щоденні операції
- Створення/редагування товарів і варіантів
- Оновлення залишків і доступності
- Контроль замовлень і вартості доставки
- Обробка контактних звернень
- Оновлення hero‑банерів і промо‑текстів

## Товари та варіанти
### Обов’язкові дані
- Назва
- Опис
- Категорія
- Мінімум 1 зображення
- Мінімум 1 варіант

Кожен варіант:
- Назва
- Об’єм + одиниця
- Ціна
- **Вага (грами)**
- Залишок + доступність

### Best Seller
- Позначте **хоча б один варіант** як Best Seller, щоб товар показувався у “Top Products” на головній.

### Архів
- Архівні товари не показуються у магазині.

## Доставка (Admin → Spedizione)
Значення використовуються в checkout і у попередньому розрахунку.
- **Tariffa per grammi (EUR)**: ціна за грам
- **Costo fisso (EUR)**: фіксована сума на замовлення
- **Spedizioni ricorrenti (EUR)**: фіксована сума для регулярної доставки

Формула:
```
доставка = (загальнаВагаГр * тарифЗаГрам) + фіксованаСума
```

Якщо вага відсутня — доставка рахується неправильно.

## Checkout та замовлення
- Клієнт додає товари → розрахунок доставки → оплата Stripe.
- Після оплати замовлення видно в Admin і в акаунті користувача.
- Адмін змінює статуси (pending, paid, shipped, canceled).

## Промокоди
- Клієнт отримує промокод після підписки на розсилку.
- Промокоди одноразові, перевіряються у checkout.

## Контакти
- Повідомлення з форми видно у **Admin → Submissions**.
- Статуси: new / resolved / rejected.

## Email шаблони
- Лише текст, редагуються у **Admin → Emails**.
- Зберігайте плейсхолдери: `{{name}}`, `{{orderId}}`, `{{products}}`.

## Типові проблеми
- **Доставка = 0** → немає ваги або не задані тарифи.
- **Top Products порожній** → немає Best Seller варіанта.
- **Товар не видно** → архівний або недоступний.

Для нових функцій звертайтесь до команди розробників.
