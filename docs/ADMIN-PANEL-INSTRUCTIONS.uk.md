# Адмін-панель — коротка інструкція

## Доступ
- Сторінка логінації: `/auth/login` (підтримує `?redirect=/admin/...`).
- Адмінка: `/admin`.

## Ролі
- **developer**, **superadmin** — повний доступ.
- **admin** — обмежений доступ (залежить від розділу).

## Навігація
- **Dashboard** — загальна статистика.
- **Ordini** — список замовлень і сторінка деталей замовлення.
- **Prodotti** — керування каталогом.

## Типовий сценарій
- Зайди в `/admin` → якщо не залогінена, буде редірект на `/auth/login?redirect=/admin`.
- Після входу відкрий потрібний розділ у сайдбарі.

## Prodotti (каталог)
- **Список**: пошук + (за потреби) показ архівних.
- **Створити**: `/admin/products/new`.
- **Редагувати**: `/admin/products/[id]`.
- Обов’язкові поля для збереження: **ID**, **Titolo**, **Slug**, **SKU**, **Descrizione**.
- **Архівація**: це soft delete (товар не видаляється з БД).

## Замовлення
- Перегляд списку + деталі (позиції, суми, статуси).

## Примітки
- Каталог на вітрині: база = mock-продукти, адмінка зберігає **DB override** (значення з БД перекривають mock для того ж `id`).
- Якщо товар не видно: перевір `archived`, `isAvailable` і `stock` (для товару та/або варіантів).
