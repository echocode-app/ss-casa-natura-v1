# Admin Panel — краткая инструкция

## Доступ
- Страница логина: `/auth/login` (поддерживает `?redirect=/admin/...`).
- Админка: `/admin`.

## Роли
- **developer**, **superadmin** — полный доступ.
- **admin** — ограниченный доступ (зависит от раздела).

## Навигация
- **Dashboard** — общая статистика.
- **Ordini** — список заказов и детальная страница заказа.
- **Prodotti** — управление каталогом.

## Типовой сценарий
- Откройте `/admin` → если не залогинены, будет редирект на `/auth/login?redirect=/admin`.
- После входа выберите раздел в сайдбаре.

## Prodotti (каталог)
- **Список**: поиск + (опционально) показ архивных.
- **Создать**: `/admin/products/new`.
- **Редактировать**: `/admin/products/[id]`.
- Обязательные поля для сохранения: **ID**, **Titolo**, **Slug**, **SKU**, **Descrizione**.
- **Архивация**: soft delete (товар остаётся в БД).

## Заказы
- Список + детали заказа (позиции, суммы, статусы).

## Примечания
- Каталог витрины: база = mock-продукты, админка сохраняет **DB override** (БД перекрывает mock по тому же `id`).
- Если товар не виден: проверьте `archived`, `isAvailable` и `stock` (для товара и/или вариантов).
