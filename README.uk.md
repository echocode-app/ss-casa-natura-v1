# ss-casa-natura-v1 Backend

Бекенд для мультисторінкового вебсайту з управлінням продуктами, замовленнями, користувачами та адмін-панеллю. Підтримує інтеграцію зі Stripe для платежів, Mailchimp для контактної форми, JWT-автентифікацію, MongoDB для збереження даних, а також логування з емодзі (`❌`, `✅`, `🚀`, `🔋`, `💡`) для зручного відслідковування стану серверу.

## Основні функціональні можливості

- Продукти з промо та сезонними знижками, категоріями та підкатегоріями
- Сортування та фільтрація продуктів по популярності, ціні та категорії
- Деталі продукту, схожі товари (`relatedProducts`) та товари, що купують разом (`upsellProducts`)
- Замовлення з перевіркою наявності, застосуванням промокодів, розрахунком доставки по вазі та створенням Stripe PaymentIntent
- Адмін-панель для керування продуктами, замовленнями, промокодами та користувачами
- Користувацькі акаунти з реєстрацією, логіном, редагуванням профілю, зміною пароля та історією замовлень
- Контактна форма з відправкою через Mailchimp
- Логи серверу з емодзі для різних типів повідомлень (`❌` – помилка, `✅` – успіх, `🚀` – відправлено, `🔋` – сервер працює, `💡` – інфо)

## API

### Продукти

- `GET /api/products` – отримати список продуктів із фільтром за категорією та сортуванням (`popularity` або `price`).  
- `GET /api/products/[slug]` – отримати деталі одного продукту, включно з промо/знижками, схожими товарами та upsell.  
- `GET /api/products/[slug]/related` – отримати схожі товари для конкретного продукту.  
- `GET /api/products/[slug]/upsell` – отримати товари, які купують разом із вибраним продуктом.  

### Замовлення

- `POST /api/orders` – створення замовлення та генерація Stripe PaymentIntent. Перевірка наявності товарів, застосування промокодів, розрахунок доставки по вазі, сповіщення користувача та власника сайту через Mailchimp.  
- `GET /api/users/me/orders` – отримати історію замовлень користувача (MVP).

### Контакт

- `POST /api/contact` – відправка контактної форми через Mailchimp.

### Адмін-панель (всі роути захищені JWT та роллю `admin`)

- `GET /api/admin/products` – отримати всі продукти  
- `POST /api/admin/products` – створити продукт  
- `PUT /api/admin/products/[id]` – оновити продукт  
- `DELETE /api/admin/products/[id]` – видалити продукт  

- `GET /api/admin/orders` – отримати всі замовлення  
- `PUT /api/admin/orders/[id]` – змінити статус замовлення (`pending`, `paid`, `shipped`, `canceled`)  

- `GET /api/admin/promocodes` – отримати всі промокоди  
- `POST /api/admin/promocodes` – створити промокод  
- `PUT /api/admin/promocodes/[id]` – оновити промокод  
- `DELETE /api/admin/promocodes/[id]` – видалити промокод  

- `GET /api/admin/users` – отримати всіх користувачів  
- `PUT /api/admin/users/[id]` – оновити дані користувача  
- `DELETE /api/admin/users/[id]` – видалити користувача  

### Користувач (акаунт)

- `POST /api/auth/register` – реєстрація користувача  
- `POST /api/auth/login` – логін користувача, JWT та cookie  
- `GET /api/users/me` – перегляд профілю  
- `PUT /api/users/me` – редагування профілю  
- `POST /api/users/me/password` – зміна пароля  

## Особливості товарів

- SEO: title, description, og:image  
- Ціна: original, promo, seasonal, fixed  
- Категорія + підкатегорія  
- Властивості: вага, об’єм, колір, склад  
- Наявність / SKU  
- Популярність → сортування по продажах  
- Рекомендації: relatedProducts + upsellProducts  

## Технології

Node.js + Next.js (App Router, Route Handlers)
MongoDB + Mongoose
Stripe (оплата)
Mailchimp (контактна форма)
JWT та cookie для автентифікації
TypeScript
TailwindCSS для фронтенду

## Налаштування

1. Встановити залежності:
npm install

2. Створити .env.local на основі .env.example:
MONGO_URI=""
JWT_SECRET=""
STRIPE_SECRET_KEY=""
MAILCHIMP_API_KEY=""
MAILCHIMP_LIST_ID=""

3. Запуск локального серверу:
npm run dev

4. Swagger API документація (після інтеграції):
http://localhost:3000/docs
